차트 기능 추가 개선·리뷰 — 2026-11-13

발견한 문제와 변경
- 배당 CSV 요청이 실패하면 주가까지 표시되지 않음.
  → 두 자료의 성공/실패를 나눠 처리하고, 주가는 유지하면서 배당 자료 오류 안내.
- 빈 가격을 Number('')로 바꾸어 0으로 표시할 수 있었음.
  → 이름으로 CSV 열을 찾고 날짜/빈 값/유한한 숫자/음수 여부를 검증. 제외 행 수 표시.
- 배당 날짜가 주가 CSV에 없으면 배당금이 차트에서 누락됨.
  → 두 자료 날짜를 합친 시간축 사용. 없는 값은 null로 유지하며 0과 구분.
- 심볼을 입력하지 않아도 차트 프로그램 전체를 내려받음.
  → 유효한 주가를 확인한 뒤 차트 모듈을 불러오도록 분리.
  초기 JS 파일은 약 559KB에서 약 5.3KB로 감소. 실제 차트를 그릴 때 약 558KB 추가 다운로드.
  압축 전 파일 크기 기준이며 총 라이브러리 용량을 줄인 것은 아님.
- 오류 후 페이지 전체를 다시 열어야 했음.
  → 다시 불러오기 버튼, 중복 로딩 방지, 기존 차트/크기 관찰자 정리.
- 과거 가격의 의미가 분명하지 않았음.
  → 날짜 범위와 마지막 종가, '실시간 아님'을 함께 표시.

구현 후 리뷰 수정
- 배당 자료가 없을 때 비어 있는 배당 축과 범례를 숨김.
- 재시도 중 버튼 초점 유지, 성공하면 결과 안내로 초점 이동.
- 심볼 입력의 HTML pattern에서 하이픈을 이스케이프.
- 실제 화면에서 범례와 기간 조절 막대가 겹쳐 범례를 위쪽에 배치.

검증
- npm test: 13개 통과. CSV 따옴표/BOM/CRLF, 누락 값, 유효하지 않은 날짜,
  중복 날짜, 잘못된 헤더, 배당 전용 날짜, 0값 보존 포함.
- 전체 빌드: 24페이지. Astro 오류 0, 경고 0, 기존 복사 API 힌트 1.
- 브라우저 자동 확인 10개 통과:
  빈 화면/잘못된 심볼에서 차트 모듈 미요청, 배당만 실패 시 주가 표시,
  재시도 정상 복구/중복 canvas 없음, 유효 주가 없음 처리, 실제 AAPL 자료,
  1440/768/390px 가로 넘침 없음.
- 추가 입력 검증: AAPL, BRK-B, ^GSPC 허용. bad/symbol 거부.
- 실제 AAPL 주가 기록: 1980-12-12 ~ 2023-07-21, 마지막 종가 191.94달러.
  해당 자료의 마지막 값이지 현재 가격이 아님.
- 실제 AAPL 배당 CSV 79행, 제외 행 0.
- 실패 시나리오는 브라우저 fetch를 시험용 응답으로 대체하여 재현.
  실제 AAPL 시나리오는 외부 원본 CSV를 직접 요청하여 확인.

남은 제한
- ECharts 본체의 500kB 초과 빌드 경고는 남음. 실제 표시 시 다운로드 비용은 동일.
- 외부 CSV의 갱신은 자동화하지 않았음. 최신 데이터라고 보장하지 않음.
- 실제 휴대전화, 화면 읽기 프로그램, 장시간 불안정한 네트워크는 미검증.
- 커밋/푸시/배포는 진행하지 않음.
