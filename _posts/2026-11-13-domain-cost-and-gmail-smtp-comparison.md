## 비교 기준

일반 영문 도메인 1개를 등록하는 경우입니다. 프리미엄 이름·중고 도메인·대량 구매·회원 등급 할인은 제외했습니다. 해외 가격은 공개 가격표를 기준으로 하며, 결제 단계의 쿠폰 최저가를 모두 비교한 결과는 아닙니다.

- **원화 환산:** 조회 시 표시된 1달러 = **1,335.03원**. [Investing.com USD/KRW](https://www.investing.com/currencies/usd-krw)의 비교용 환율이며 카드 청구 환율이 아닙니다.
- **해외 금액:** 원 단위 반올림. 별도 세금과 해외 결제 수수료 제외. Spaceship은 표기된 ICANN 수수료 연 $0.20 포함.
- **국내 금액:** 부가세 별도 가격에 10%를 더해 부가세 포함으로 통일.
- **3년 합계:** 첫해 가격 + 현재 갱신 가격 × 2. 미래 요금 인상·환율 변화가 없다는 가정의 비교값이며, 실제 3년 선결제 견적과 다를 수 있습니다.

## 무료 메일에서 구분할 세 가지

1. **메일 전달:** `hello@내도메인`으로 온 메일을 기존 Gmail로 보내 줍니다. 별도 도메인 메일함이나 발송 권한이 생기는 것은 아닙니다.
2. **메일함:** 업체 서버에 메일을 저장하고 웹메일이나 메일 앱에서 읽고 보냅니다. 무료·유료 여부와 계정 수·용량을 확인해야 합니다.
3. **외부 SMTP:** Gmail의 ‘다른 주소로 메일 보내기’에 연결할 발송 서버입니다. SMTP는 메일을 보내는 통신 방식으로, 인증 계정과 Gmail이 연결할 수 있는 보안 설정이 필요합니다.

Gmail에서도 다른 주소로 발송할 수 있지만 도메인 구매나 수신 전달만으로 자동 설정되지는 않습니다. [Gmail 공식 설정 안내](https://support.google.com/mail/answer/22370?hl=ko)를 기준으로 해당 메일 서비스의 SMTP 정보를 연결해야 합니다.

## 도메인 비용만 내고 Gmail을 활용하는 구성

발송량이 적다면 등록 업체와 메일 서비스를 나누는 방법이 있습니다.

<div class="table-scroll" tabindex="0" role="region" aria-label="Gmail 구성 비교">

| 역할 | 구성 후보 | 비용·조건 |
|---|---|---|
| 도메인 | 원하는 등록 업체 | 등록·갱신 비용 |
| 사이트 | GitHub Pages | 공개 저장소의 정적 사이트 호스팅·HTTPS 무료 |
| 수신 | Cloudflare Email Routing → 기존 Gmail | 무료, Cloudflare DNS와 목적지 주소 인증 필요 |
| 발송 | SMTP2GO Free → Gmail ‘다른 주소로 메일 보내기’ | 월 1,000통·하루 200통 한도, 계정·발신 도메인 인증 필요 |
| 메일 읽기·작성 | 기존 개인 Gmail | 별도 도메인 메일함을 Google이 운영하는 방식과는 다름 |

</div>

[SMTP2GO 무료 요금제](https://support.smtp2go.com/hc/en-gb/articles/223087947-Free-Plan)는 기간 제한 없이 사용할 수 있다고 안내하며, [Gmail 연결 가이드](https://www.smtp2go.com/setupguide/gmail/)도 제공합니다. 월 한도에 도달하면 추가 발송 요청이 거절되므로 사용량 확인이 필요합니다. 이는 공식 문서를 토대로 한 구성 제안이며, 이 글 작성 과정에서 실제 송수신 시험은 하지 않았습니다.

[GitHub Pages의 개인 도메인 HTTPS 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https)에 따라 정상 설정한 개인 도메인에도 HTTPS를 사용할 수 있습니다. 이 블로그처럼 GitHub Pages를 이용한다면 도메인 업체의 웹호스팅이나 SSL 상품이 필수 구매 항목은 아닙니다.

## 현재 판단과 앞으로 확인할 것

공개 가격표 기준으로 .com은 Spaceship, 국내 .kr은 비아웹이 비용 측면에서 유리했습니다. 다만 메일 송수신까지 한 업체에서 처리할지, 수신 전달과 무료 SMTP를 조합할지에 따라 편의성과 전체 비용이 달라집니다.

다음 검토 항목은 신규·갱신 가격, 할인 적용 조건, 도메인 등록자의 개인정보 보호 범위, 무료 SMTP의 정책과 발송 한도, 닷홈의 보안 연결 조건입니다. 확인된 변경은 같은 글에 반영하고 변경 이력을 남깁니다.

## 비교 후 실제 선택

그동안 도메인은 국내 업체에서 구매했습니다. 이번에는 가격과 서비스를 비교한 뒤 해외 업체를 이용해 보기로 했고, 네임서버 선택의 자유와 지원 방식을 고려해 최종적으로 Porkbun에서 등록했습니다.

이 내용은 비교 이후의 구매 결정에 대한 후기입니다. 위 가격표와 서비스 조건의 자료 확인 기준일은 2026년 11월 13일이며, 구매 후기를 추가하면서 요금 전체를 다시 검증한 것은 아닙니다.
